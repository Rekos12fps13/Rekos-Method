# Rekos Uploader
Chrome Manifest V3 extension for HD/4K creator workflows.

Features:
- Watch multiple local HD/4K videos in a responsive grid.
- Inspect file type and size before upload.
- Recommended source profile: up to 2160p, source FPS, MP4/H.264, AAC.
- TikTok page quality assistant.

Important: TikTok controls server-side re-encoding. An extension cannot guarantee zero recompression or bypass TikTok limits. This build does not bypass authentication, DRM, upload limits, or server processing.

Install: extract this folder, open chrome://extensions, enable Developer mode, then Load unpacked and select the folder containing manifest.json.
